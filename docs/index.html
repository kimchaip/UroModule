CalendarSync

CalendarSync is a personal Google Apps Script that keeps a calendar library in the Memento Database app in sync with the owner's own Google Calendars.

What it does

  • When an entry is created, changed or deleted in Memento, the same event is created, changed or deleted in Google Calendar.
  • Changes made in Google Calendar are collected every 30 minutes and pulled into Memento when the owner presses "Sync now".

The script runs in the owner's own Google account and only works with calendars that account owns or has been given access to. It is not offered as a service to other people.
