CalendarSync privacy policy

Last updated: 20 October 2026

Data the app accesses

CalendarSync uses the Google Calendar permission to read, create, change and delete events (title, date and time, description, location and reminders) in the calendars of the Google account that installed it. It does not access any other Google data.

How the data is used

Event data is used only to keep the owner's Memento Database calendar library and the owner's Google Calendars in sync.

Storage

Pending changes waiting to be synced are kept briefly in the Script Properties of the owner's own Apps Script project and are removed once Memento has received them. Calendar IDs are kept in the same place. Nothing is stored on any other server.

Sharing

CalendarSync does not sell, share or transfer calendar data to anyone, and does not use it for advertising or analytics. Data only moves between the owner's Google Calendar and the owner's Memento app.

Removing access

The owner can remove CalendarSync's access at any time at myaccount.google.com/permissions.

Contact

Questions can be raised as an issue at github.com/kimchaip/UroModule/issues.
